# Photos de la galerie

Déposez ici les photos du local et des services (format paysage, JPG, idéalement 1600 px de large, < 300 Ko).
Chaque photo apparaît automatiquement dans la galerie ; tant qu'un fichier manque, une vignette « Photo à venir » s'affiche.

| Fichier            | Emplacement dans la galerie              |
|--------------------|------------------------------------------|
| `local.jpg`        | Grande vignette : façade · Cosider, Ali Mendjeli |
| `accueil.jpg`      | Accueil & conseil                        |
| `cybercafe.jpg`    | Espace cybercafé                         |
| `etudiants.jpg`    | Dossiers étudiants                       |
| `demarches.jpg`    | Démarches administratives                |
| `informatique.jpg` | Service informatique (vignette large)    |

Astuce : utilisez les mêmes photos que sur la fiche Google Business Profile pour une image cohérente.
